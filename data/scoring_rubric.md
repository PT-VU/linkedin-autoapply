# Candidate-specific scoring rubric

Replace this file with the candidate's own requirements. The AI must use the
candidate profile, resume facts, and this rubric; it must not infer personal
facts that are not present in those files.

## Suggested evaluation order

1. Identify the actual role and seniority from the full JD.
2. Check explicit hard blockers defined by the user.
3. Compare technical responsibilities with evidence from the resume.
4. Compare career direction, practical constraints, language, and location.
5. Return a 0-10 score, a decision, confidence, and concise evidence.

## User-defined hard blockers

List only conditions the candidate wants to exclude. Keep unknown facts as
unknown and route them for review instead of inventing an answer.

## User-defined preferences

List target role families, acceptable adjacent roles, location preferences,
language preferences, experience range, work authorization facts, and any
other truthful constraints.
